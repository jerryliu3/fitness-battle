# Activity comparisons: iOS review

Reviewed on an iPhone 17 Pro simulator (iOS 26.5) using a temporary local preview and fictional, in-memory activity history. The preview used the real activity sheet and comparison components; it was removed after review.

- [GPS route and moving-time comparison](ios-gps-route.png)
- [GPS pace comparison](ios-gps-pace.png)
- [Strength session frequency](ios-strength-sessions.png)
- [Strength average heart rate](ios-strength-heart-rate.png)

On the simulator, switching comparison controls updated the visible values and the accessibility description. The GPS route displayed its recorded outline; the preview did not exercise a live map service. The frequency chart's accessibility description names the 30-day period, including when the previous count is zero.
