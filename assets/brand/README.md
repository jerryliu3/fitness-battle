# Overtaek polished capsule identity

The selected production mark uses a pair of vertical polished-glass capsules at **162.5% scale**, with **four fading echoes** behind each capsule. Solar Gold (`#ffc400`) leads Cool Platinum (`#c9d6e3`) on white. Black-background versions use the same colors and geometry. Echoes flow backwards in the lane UI; reduced-motion and inactive-screen states use the still arrangement.

`overtaek-icon.svg` and `overtaek-icon-black.svg` are the vector masters. The shared geometry and palette live in `packages/shared/src/polished-identity.ts`; run `node scripts/generate-app-icons.mjs` to regenerate the platform assets after installing workspace dependencies.

- Web metadata supplies the SVG tab icon, multi-size favicon, and 180px Apple touch icon. The manifest supplies 192px and 512px install icons plus a padded maskable icon.
- Expo supplies the 1024px app icon, transparent padded Android adaptive foreground, monochrome mask, and web favicon. The launcher supplies the adaptive icon background.
- White and black web icon sets are available under `apps/web/public/icons/white/` and `black/`. A black-background native icon is also available as `apps/mobile/assets/icon-black.png` with its adaptive foreground. These are explicit assets for conditional use.

Adaptive artwork is padded for launcher safe areas. Native icon changes take effect in a newly built app binary; this change does not submit or release an app.

Earlier circle, wake, material, and scale explorations remain in `docs/design-studies/the-pass`. They are preserved as design history and are not regenerated by the app-icon script.
