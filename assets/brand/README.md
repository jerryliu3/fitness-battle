# Overtaek app icon

The launcher, store, and web install mark is the black ring with the gold arrowhead (`#F7C948`) on white. `overtaek-mark.png` is the raster master. Run `node scripts/generate-app-icons.mjs` to regenerate the platform assets after installing workspace dependencies.

Lane capsules stay in `packages/shared/src/polished-identity.ts`. Regenerating app icons leaves that geometry alone.

- iOS and Expo use `apps/mobile/assets/icon.png`: a 1024×1024 PNG with no alpha. The artwork sits inside the center 70% so the arrow tips clear the iOS squircle.
- The Google Play listing icon is `docs/store/play-icon-512.png`: a 512×512 32-bit PNG under 1 MB, with the same composition.
- Android adaptive foregrounds and the web maskable icon keep the artwork inside the adaptive safe circle (a 66dp keyline on the 108dp launcher canvas). The adaptive background is `#ffffff`.
- `apps/mobile/assets/monochrome-icon.png` is the black silhouette of the ring and arrow for themed launchers.
- Web metadata uses `apps/web/src/app/icon.png`, a 180px Apple touch icon, a multi-size favicon, and the 192px and 512px icons in `apps/web/public/icons/`.

White and black web icon folders carry the same white-field mark. A black-background native file is at `apps/mobile/assets/icon-black.png` for conditional use. Native icon changes appear in a newly built app binary.

Earlier circle, wake, material, and scale explorations remain in `docs/design-studies/the-pass`. They are design history and are not regenerated by the app-icon script.
