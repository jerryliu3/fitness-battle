## Research and interpretation

- [Apple: Create icons with Icon Composer](https://developer.apple.com/videos/play/wwdc2025/361/) supports simple vector layers and inspecting scale and appearance modes. This study tests flat graphic form before adding system materials; masks are preview-only.
- [Android: Adaptive icons](https://developer.android.com/develop/ui/compose/system/icon_design_adaptive) documents varying masks, foreground/background layers and monochrome artwork. Circle comparison and unmasked exports expose potential composition problems early. These previews are not certified Android safe-zone templates.
- [Duolingo: Shape language](https://blog.duolingo.com/shape-language-duolingos-art-style/) supplies a precedent for coherent character geometry. The interpretation here is to test the actual Ember contour alongside explicitly separate spark and playful-token alternatives.
- [Nielsen Norman Group: The role of animation and motion in UX](https://www.nngroup.com/articles/animation-purpose-ux/) discusses purposeful feedback and the attention cost of movement. This study opens at the final static frame, plays on request and retains manual still-frame review with reduced motion.

These sources inform constraints, not a prediction of which identity users will prefer. Twin trails, Ember pursuit and Lane cut are proposed starting points for another round, with Slipstream and Afterimage worth retaining for their distinct softer and outline-led possibilities.

The user’s references are the [Everyday Club product](https://fitness-battle-4xnxaa6h3-jerry-goals-projects.vercel.app/design/brand?concept=everyday-club&view=product), [refined Chase wordmark](https://fitness-battle-one.vercel.app/design/motion?experience=logo&concept=chase-stagger&round=refined), and [Photo Combo return moment](https://fitness-battle-one.vercel.app/design/motion?experience=overtake&concept=photo-combo&round=refined). Those URLs require authentication; the matching in-repo source, canonical Ember model, brand guide and motion review notes were inspected directly. The installed Next 15.5.27 package does not include the requested `dist/docs/` directory, so the official layouts/pages and client-component documentation were consulted as a fallback before adding the thin route.
